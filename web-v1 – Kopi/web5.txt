0) Fast mapping og produktregler (MÅ IKKE endres)
0.1 Canonical “Verdict” mapping (Noise vs Structural)

Bruk canonical MetaFile.meta.regime:

Verdict = “Insufficient data” hvis:

meta.missing === true, eller

meta.regime.gate.status ∈ {BLOCKED,DEGRADED,UNKNOWN} (future schema), eller

confidence_score < gating_threshold (der gate-felt ikke finnes)

Ellers:

label === "STABLE" → Verdict = “Likely noise”

label in {"HEATING","CONGESTED","CHEAP"} → Verdict = “Structural shift”

alt annet → Insufficient data (ikke “gjett”)

0.2 “Why” (forklaring)

Basic: 1–2 setninger basert på meta.regime.drivers (top 1–3) og meta.regime.axes.

Advanced: vis driverstats (pct_90d, z_robust, momentum_7d_vs_30d) + axes bands/trend.

Ingen normative ord (“good/bad”, “buy/sell”, “should”).

0.3 Produktkrav

Ingen prisdata, ingen prognoser, ingen rådgivning.

Alle dimensjoner (as-of, window, lag, coverage, threshold used, gate status) skal være eksplisitte i UI.

1) src/app/chains/[chain]/ChainClient.tsx (KRITISK)

Mål: ChainClient skal eie custom threshold state og gjøre /api/regime/custom til en faktisk produktflyt.

Krav (konkret)

State i ChainClient

customEnabled: boolean

overrides: ThresholdConfigOverridesV1 (minimal overrides-objekt)

panelOpen: boolean (ThresholdPanel åpne/lukke)

customResult: CustomRegimeResult | null

customLoading: boolean

customError: string | null

Når customEnabled endres

Hvis customEnabled === false:

Sett customResult = null (eller behold siste men ikke vis)

Hvis customEnabled === true:

Kall /api/regime/custom med:

chain

date = canonicalMeta.regime.asof_date (eller “latest” hvis du ikke har asof)

body { config: overrides }

Sett customLoading + customError deterministisk.

Persistens

LocalStorage per chain (minstekrav):

customEnabled og overrides

Key-forslag:

regime.custom.enabled.<chain>

regime.custom.overrides.<chain>

Viktig: parsing må være defensiv (safe JSON parse).

Wiring til eksisterende komponenter

ChainDiagnosticHeader skal få:

canonicalMeta={canonicalMeta}

customResult={customResult}

customEnabled={customEnabled}

onOpenThresholdPanel={() => setPanelOpen(true)}

ThresholdPanel rendres fra ChainClient (typisk som drawer/modal/inline)

Props:

enabled={customEnabled}

onChangeEnabled={setCustomEnabled}

overrides={overrides}

onChangeOverrides={setOverrides}

onClose={() => setPanelOpen(false)}

chain={chain}

date={canonicalMeta.regime.asof_date ?? null} (for “Copy curl”)

Ingen hook-order feil

Ikke conditionally declare hooks.

All conditional rendering må ligge i JSX, ikke rundt hooks.

Aksept/QA

7) src/app/api/regime/custom/route.ts (MÅ verifiseres/patches)

Mål: Route må støtte GET (defaults) og POST (overrides), og returnere deterministisk payload som UI kan vise.

Krav (det UI trenger)

Respons må inkludere (min):

ok: true/false

chain

date_requested (string: “latest” eller ISO)

ok:false + error + message

Ikke throw uformatert JSON
