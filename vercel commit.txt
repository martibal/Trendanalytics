Ja. Bruk denne enkle bryteren i Vercel:

```txt
Vercel → Project → Settings → Build and Deployment → Ignored Build Step
```

## Deploy på hver push/commit: PÅ

Sett:

```txt
Behavior: Run my Bash script
Command: exit 1
```

Betyr:

```txt
exit 1 = build/deploy
```

## Deploy på hver push/commit: AV

Sett:

```txt
Behavior: Don’t build anything
```

Dette tilsvarer:

```txt
exit 0 = skip build/deploy
```

## Din praktiske bruk

Når du jobber med kode/design og vil at Vercel skal oppdatere offentlig side:

```txt
Run my Bash script → exit 1
```

Når du er ferdig og bare vil at data-workflow/deploy hook skal styre oppdateringene:

```txt
Don’t build anything
```

Så lagrer du med **Save**.

Det er hele av/på-bryteren.
