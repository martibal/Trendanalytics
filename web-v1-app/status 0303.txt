This is a technical continuation guide, not a strategy summary.

2. Non-Negotiable Governance Constraints

These rules must never be violated.

2.1 Strictly Descriptive

No price data

No forecasts

No advisory language

No inferred conclusions

No derived models beyond published JSON

Frontend may only:

Read published JSON artifacts

Display values

Sort / window deterministically

Format numbers for UI

It may NOT:

Recompute models

Apply additional smoothing

Change regime logic

Add interpretation text

2.2 Deterministic Transparency

All UI values must trace directly to:

/public/data/published/v1/

Displayed values must expose source paths where appropriate.

2.3 Data Hierarchy (Immutable Contract)
RAW parquet
  → gold parquet
    → gold/YYYY-MM-DD.json
  → derived/YYYY-MM-DD.json
  → meta/<chain>/latest.json
  → dataset.json

Frontend consumes only:

meta

gold (daily)

derived (daily)

dataset.json

4.2 Chart System
Data Source Strategy

public/data/published/v1/derived/<chain>/YYYY-MM-DD.json

public/data/published/v1/gold/<chain>/YYYY-MM-DD.json

Aggregation logic:

Determine max available date from derived disk files

Build dense 90-calendar-day window

Read matching daily files

Join by date

Preserve null gaps

No interpretation applied

9. “Do Not Break” Rules for Developers

Never introduce price fields

Never compute new metrics in frontend

Never modify confidence thresholds without backend change

Never infer conclusions from combinations of values

Never apply smoothing beyond MA fields already published

Never remove determinism hash display

10. Testing Checklist

Before merging any PR:

Window remains deterministic 90 calendar days

No interpretation text introduced

Drivers sorted by |z|

Confidence band matches numeric threshold

No async misuse in server components

No conditional hook usage in client components
