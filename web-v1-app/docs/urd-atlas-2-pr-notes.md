# PR notes

This branch is intended as a first product-architecture implementation of Urd Atlas 2.0.

It should be reviewed as a product direction and route structure before being treated as production-ready code.

## Review focus

- Does the new homepage answer what the product is for?
- Does Analyst Kit make Urd Atlas useful for users without a pipeline?
- Does Workflows make the technical integration path concrete enough?
- Does Validation honestly expose the proof burden?
- Does navigation make the new product surfaces discoverable?

## Do not merge before

- lint
- typecheck
- build
- visual inspection
- review of all new claims against the actual data contract
