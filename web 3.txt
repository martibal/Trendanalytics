# 🔁 OVERLEVERING – BLOCKCHAIN TREND CONTEXT (PRICE-AGNOSTIC)

## 1. Formål og produktdefinisjon (viktig kontekst)

Dette prosjektet er en **deskriptiv, pris-agnostisk analyseplattform for blockchain-aktivitet**, med fokus på:

* **Bitcoin**
* **Ethereum**
* **Arbitrum**
* **Base**

Plattformen:

* viser **trender, nivåer og stabilitet** i nettverksaktivitet
* gir **kontekstualisert innsikt**, ikke signaler eller anbefalinger
* **inkluderer aldri prisdata, prognoser eller rådgivende språk**
* er bygget for både:

  * **amatører** (enkle forklaringer, paneler, tekst)
  * **profesjonelle** (full metodikk, rådata, JSON, revisjonsspor)

All data er **reproduserbar, revisjonerbar og audit-vennlig**.

---

## 2. Overordnet arkitektur

Systemet består av **tre hovedlag**:

### A) Data pipeline (offline / batch)

* Laster ned **rå blockchain-data** (blocks + transactions) daglig fra AWS
* Aggregerer dette til:

  * **daily features**
  * **gold timeseries**
  * **weekly gold**
* Eksporterer:

  * `gold`
  * `derived`
  * `meta`
* Publiserer et **immutabelt dataset** per kjøring:

  ```
  data/published/v1/
    └── {genre}/{chain}/
         ├── day/
         ├── latest.json
         ├── lastXd.json
         └── manifest.json
  ```

Pipeline er:

* **inkrementell**
* **robust mot manglende dager**
* **ikke avhengig av full rekjøring**

---

### B) Web API (Next.js App Router)

Web-laget leser **kun fra `public/data/published/v1`**
→ ingen direkte kobling til pipeline eller rådata.

Alle API-endepunkter er **read-only** og deterministiske.

#### Viktige API-ruter:

* `GET /api/series`
* `GET /api/summary`
* `GET /api/health`

---

### C) UI / Frontend (Next.js + React)

Frontend er bygget som et **pedagogisk, eksplorativt dashboard**:

* Landing (Trend Context)
* Chains
* Notables
* Methodology
* Wiki
* About

Hver visning:

* er **100 % deskriptiv**
* viser **rå + smooth data**
* forklarer:

  * hva du ser
  * hvorfor det er relevant
  * hvilke begrensninger som finnes

---

## 3. Hva som er ferdig og på plass (status nå)

### ✅ Data & pipeline

* Rådata lastes daglig fra AWS (verifisert)
* Inkrementell catch-up fungerer
* Gold / Derived / Meta er konsistente
* `asof` er verifisert lik i:

  * calculated
  * published
  * web-served data
* Forskjellig latency per chain er eksplisitt håndtert:

  * BTC / ETH: near-real-time
  * Arbitrum / Base: ca. 1 uke forsinkelse

---

### ✅ Web API (implementert og i bruk)

**`/api/series`**

* Returnerer timeserie (raw + smooth)
* Krever eksplisitt:

  * `chain`
  * `metric`
  * `start`
  * `end`
* Leser direkte fra published gold JSON

**`/api/summary`**

* Returnerer:

  * level
  * trend
  * stability
  * forklarende tekst
* Samme datakontrakt som UI-panelene

**`/api/health`**

* Validerer:

  * tilgjengelige chains
  * genres
  * asof-konsistens
* Tolerant mot formatendringer i meta

---

### ✅ UI / Frontend

* Trend Context landing fungerer
* 4 kjeder vises korrekt
* Paneler viser:

  * Level
  * Trend
  * Stability
* Forklarende tekst er til stede
* Rå + smooth linjer i chart
* Data notes (asof, latency) vises tydelig
* “Raw reports” lenker er eksponert

Dette er **ikke en prototype**, men et sammenhengende system.
